我正在构建 **引力AI（Yinli AI，原名 FitMeet）**：一个以人为核心、由 Agent 作为社会连接器的 **SI（Social Intelligence）原生人际互联即时通讯网络**。

I am building **Yinli AI (formerly FitMeet)** — an AI-native social messaging network where people remain at the center and Agents help connect people, relationships, and real-world action.

## 我主要做什么 · What I build

- **端到端产品与运行时**：把 Agent 的意图理解、工具选择、业务事实、授权回执连接到网站与 iOS 的统一结果流。
- **人际连接与即时通讯**：围绕附近、组局、群聊、悬赏和赚钱等入口，推进需求、能力、候选人、邀请、组局与消息闭环。
- **可靠的社交动作**：使用精确授权、来源版本、隐私/可见范围校验和幂等回执，让连接、邀请和沟通可以恢复、可追溯。
- **Agent Runtime**：集成完整 Pi 原生会话，处理长会话、上下文压缩、有界工作集、检查点与重启接续。
- **MCP 与外部 Agent 生态**：建设 Streamable HTTP MCP、OAuth、双语 Agent Skill 与 Harness 插件，让外部 Agent 在授权范围内进入同一人际网络。
